3 SECONDS KITCHEN — MOBILE + PERFORMANCE EDITION

Six linked pages: index.html, menu.html, about.html, delivery.html, gallery.html, visit.html.
Optimized for 320px-wide phones, tablets and large screens. Includes accessible mobile menu and large tap targets, mobile shopping basket, improved images and intelligent video loading.

PUBLISH: Upload the CONTENTS of this folder (including media and sw.js) to your GitHub repository root. Enable GitHub Pages from Settings → Pages → main /root. Use HTTPS as provided by GitHub Pages.

LOAD: mobile hero loads one background video, desktop loads two; video playback is suppressed for data-saving / reduced-motion users. Other images load on demand.
OFFLINE: a lightweight service worker caches the app shell and viewed images on HTTPS after the first visit; online connection is still required for WhatsApp orders, Maps and social networks.
SCALABILITY: Github Pages serves a static site to many visitors but has bandwidth and usage limits; no central database or simultaneous checkout is included. Orders launch WhatsApp on EACH visitor's device, and restaurant staff must manually confirm. For sustained very high traffic or real-time shared order tracking, use a production CDN hosting plan plus a backend/database.
PRICES: not provided, so the business confirms prices, delivery fees, availability and times on WhatsApp.
