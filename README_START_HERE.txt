3 SECONDS KITCHEN - EMBEDDED MEDIA / GITHUB PAGES EDITION

This edition has 6 HTML pages and embeds ALL images and both uploaded videos into two .js files. No media folder is required.

To publish: 1. Go to https://github.com/WiseTechInnovations/3seconds-kitchen
2. Delete previous media files and obsolete sw.js to avoid old caching.
3. Upload ALL files from this ZIP to the repository root (index.html must be at root).
4. Commit changes. Go to Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. Open https://wisetechinnovations.github.io/3seconds-kitchen/

ALL these files must be uploaded, including embedded-images.js, embedded-videos.js, style.css, app.js, menu-data.js, and six .html pages.
No backend required; independent customers can make WhatsApp orders. This does not collect orders centrally or process payments.
Technical note: embedded-videos.js is large because both mp4s are completely embedded. GitHub handles it as a single file; however bandwidth scales with video viewers.
